# 🏥 Hospital Emergency Room Dashboard | Excel

## 📊 Project Overview

This project is an end-to-end *Hospital Emergency Room Dashboard* created using Microsoft Excel.

The objective of this project is to analyse hospital emergency room data and transform raw data into meaningful insights through data cleaning, analysis, KPI creation, and dashboard visualization.

## 🔍 Key Analysis

- 🏥 *Patient Admission Status* – Analysed admitted vs. not admitted patients.
- 👥 *Patient Age Distribution* – Grouped patients by different age groups.
- ⏱️ *Timeliness Analysis* – Measured the percentage of patients attended to within 30 minutes.
- ⚥ *Gender Analysis* – Analysed the number and percentage of patients by gender.
- 🏨 *Department Referrals* – Identified the departments receiving the highest number of patient referrals.
